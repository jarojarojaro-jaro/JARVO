# Po hackathonie

## Kiedy użyć
- Ogłoszono wyniki, przyszedł feedback jury albo start się nie udał (nie zdążyliśmy, odrzucenie).

## Kroki
1. Wynik ze strony hackathonu (galeria, ogłoszenie), status `wygrany` albo `przegrany` z notatką (miejsce, nagroda,
   link); nagroda do odbioru → zadanie dla @@WLASCICIEL@@ (konto, KYC i wypłata to jego decyzja).
2. Zwycięzcy: co mieli, czego my nie (kryteria, demo, tracki); 3 konkretne różnice.
3. Nasz czas: plan a rzeczywistość według etapów (MVP, demo, zgłoszenie), co zjadło najwięcej.
4. Lekcje: najwyżej 3, każda jako zmiana działania („następnym razem…”), zapis `wiedza_zapisz`; lekcja o skillu →
   propozycja zmiany skilla do poczekalni.

## Wyjścia
- `out/<id>/RETRO.md`, status w bazie, notatka w skarbcu.

## Definition of Done
- [ ] status i wynik w bazie z linkiem,
- [ ] 3 różnice ze zwycięzcami i najwyżej 3 lekcje w skarbcu.
