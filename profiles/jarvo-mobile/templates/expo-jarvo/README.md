# Aplikacja mobilna (szablon JARVO)

Zbudowana przez Twórcę aplikacji floty Jarvo. Expo SDK 57 (React Native, TypeScript, expo-router).

- Uruchomienie lokalnie: `npm install`, potem `npx expo start` (kod QR do Expo Go).
- Konfiguracja aplikacji (nazwa, identyfikatory, dane firmy, kolory, uprawnienia): `jarvo.app.json`.
- Build i sklepy: EAS (`eas.json`): profil `preview` (plik APK, wersja testowa), `production` (sklepy).
- Zasady dla agentów: `AGENTS.md`.
