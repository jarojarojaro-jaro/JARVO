# jarvo-mobile: Twórca aplikacji

Aplikacje mobilne dla małych firm od pomysłu do sklepu. Projekt, proces i granice: [docs/MOBILE.md](../../docs/MOBILE.md).

| Element | Zawartość |
|---|---|
| `SOUL.md` | main prompt: najpierw potrzeba, potem technologia; tylko źródła publiczne; dowód i numer wytycznej przy każdym wniosku; konta zawsze właściciela |
| `skills/mobile/` | 10: audyt-mobilny (+ kryteria kontroli), natywna-czy-pwa (+ macierz decyzji), nowa-aplikacja (+ szablon planu, zasady ekranów), podglad-aplikacji (+ konfiguracja Expo Go), bramka-aplikacji (+ rubryka, werdykt, testy wrogie), pakiet-do-sklepow (+ metadane i limity, potok zrzutów, mapa 44 punktów), wydanie (+ konta właściciela), odrzucenie (+ mapa odrzuceń), aplikacja-ze-strony (+ funkcje natywne i opisy dla recenzenta), utrzymanie-aplikacji (+ opinie w sklepach) |
| skille zewnętrzne | 20 z `vendor/skills.lock.yaml` (przypięte commity, skan przy buildzie): Expo (`expo/`: expo-router, expo-native-ui, expo-ui, expo-design-system, expo-animation, expo-data-fetching, expo-web-to-native, eas-app-stores, eas-update, expo-upgrade), React Native (`rn/`: react-native-best-practices i react-navigation, upgrading-react-native od Callstack, react-native-skills od Vercel), ASO (`aso/`: metadata-optimization, screenshot-optimization, app-rejection-recovery, android-aso, localization, review-management). Wysyłka opinii do Expo zablokowana w `approvals.deny` |
| `scripts/` | `audyt_mobilny.py` (App Store, Google Play, Universal Links i App Links, baner, PWA, opinie z App Store), `decyzja.py` (potrzeby → strona, PWA, Wallet, platforma albo aplikacja, z kosztami), `zgodnosc.py` (profil zgodności → wymagania sklepów i konfiguracja), `aplikacja.py` (nowa, ustaw, sprawdz, eksport, podglad, expo-go), `ikony.cjs` (ikony i ekran startowy), `zrzuty.cjs` (zrzuty iPhone i Pixel z kontrolami), `wrogie.cjs` (testy wrogie w przeglądarce), `urzadzenie.py` (Android przez adb: instalacja, zrzuty, logi, testy wrogie), `ios_ci.py` (symulator iOS w GitHub Actions), `bramka.py` (werdykt z kontroli, testów i rubryki), `sklep_check.py` (44 punkty przed wysłaniem: konfiguracja po wtyczkach, AAB i IPA, metadane, grafiki, adresy), `pakiet.py` (szkic karty, grafiki Google, zrzuty do sklepów), `kadry.cjs` (kompozycja kadrów bez alfy), `wydanie.py` (plan, EAS Build, pobranie buildów z listą kontrolną, TestFlight i testy Google, karta App Store; A2 ze zgodą), `odrzucenie.py` (wytyczne z wiadomości recenzenta, odpowiedź po angielsku, nauka listy kontrolnej), `ze_strony.py` (strona firmy → dane, oferta, funkcje natywne, szkice konfiguracji), `utrzymanie.py` (stan, kalendarz terminów z `.ics`, EAS Update za zgodą do zgodnego buildu, plan SDK), `paczki.py` (paczka npm przed instalacją: literówki, podszycia, nazwy zmyślone, świeże, skrypty instalacyjne), `mobile_lib.py` |
