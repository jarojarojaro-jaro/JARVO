# Hooki i struktury krótkich filmów

## Hooki (pierwsze 2 s)
| Wzorzec | Przykład (PL) | Kiedy |
|---|---|---|
| Liczba + obietnica | „3 błędy, przez które kawa jest gorzka.” | poradniki, listy |
| Mit do obalenia | „Espresso ma najwięcej kofeiny? Nie.” | edukacja, produkt |
| Konflikt / zaskoczenie | „Wydałem 2000 zł na ekspres. To był błąd.” | historia, recenzja |
| Pytanie z tezą | „Dlaczego kawiarnie nie używają wrzątku?” | ciekawostki |
| Efekt najpierw | „Tak wygląda idealna pianka. Oto jak.” | tutoriale (pokaż wynik w 1. kadrze) |
| Bezpośrednio do widza | „Jeśli pijesz kawę po 15:00, obejrzyj to.” | segmentacja odbiorców |
| Przed → po | „Ta sama kawa, dwa młynki. Różnica?” | porównania, produkt |

Wzorce to 7 z 18 taktyk skilla `hooki` (liczba na start, pod prąd, historia od środka, pytanie, efekt, wywołanie,
kontrast); pełna tabela, trzy warstwy i lejek diagnozy są tam.

Zasady: konkret zamiast przymiotnika; bez „cześć”, „w dzisiejszym filmie”, „mam dla was”; tekst ekranowy hooka ≤ 5 słów;
obraz hooka ma ruch albo kontrast (nie plansza z logo).

## Struktury
| Struktura | Sceny | Dobra do |
|---|---|---|
| Lista | hook → punkt 1 → punkt 2 → punkt 3 → CTA | porady, fakty |
| Mit → fakt | hook (mit) → dlaczego ludzie tak myślą → fakt + dowód → co z tym zrobić → CTA | edukacja |
| Problem → rozwiązanie | hook (ból) → skutek → rozwiązanie → dowód → CTA | produkt, usługa |
| Przed → po | hook (efekt) → przed → zmiana → po → CTA | metamorfozy, porównania |
| Mini-historia | hook (moment zwrotny) → kontekst → napięcie → rozwiązanie → morał/CTA | marka osobista |
| Tutorial | hook (efekt) → krok 1 → krok 2 → krok 3 → wynik → CTA | how-to |

## Rytm
- Zmiana obrazu co 2–4 s (nowe ujęcie, zbliżenie, tekst ekranowy); scena z lektorem > 5 s = dwa ujęcia.
- Pętla: ostatnie zdanie może łączyć się z hookiem (widz ogląda drugi raz → lepsze zasięgi).
- CTA konkretne: „Zapisz, zanim zapomnisz”, „Obserwuj po część 2”; nie „daj znać w komentarzu, co myślisz”.

## Długość (orientacyjnie)
| Cel | 9:16 | 16:9 |
|---|---|---|
| zasięg / ciekawostka | 15–30 s | — |
| poradnik / produkt | 30–60 s | 60–180 s |
| historia / explainer | 45–90 s | 2–8 min |
