# TARS

Prywatny asystent AI zbudowany na [Hermes Agent](https://github.com/NousResearch/hermes-agent)
(Nous Research): jeden agent na zewnątrz, w środku flota wyspecjalizowanych profili,
z którymi można rozmawiać osobno albo pracować przez TARS-a jako dyspozytora.

Pełny plan: [docs/PLAN.md](docs/PLAN.md)
